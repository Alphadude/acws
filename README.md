# ACWS — African & Caribbean Wedding Show

The official web experience for the **African & Caribbean Wedding Show (ACWS)**, taking place in London, United Kingdom.

## Overview

ACWS is a premier wedding showcase celebrating African and Caribbean culture, modern luxury, fashion, and curated wedding artisans. This repository contains the responsive web application and vendor registration portal.

## Key Features

- **Luxury Apple-Modern Design**: Built with refined typography (San Francisco system font stack), expansive layouts, and crisp high-contrast accents.
- **Event Highlights & Run of Show**: Full runway schedules, wedding workshops, live entertainment lineups, and visitor guides.
- **Exhibitor & Vendor Registration Portal (`exhibitor-registration.html`)**:
  - Multi-step interactive application form.
  - Transparent stand pricing calculator (Standard, Corner, Island, Runway Feature stands).
  - Power drops, staging extras, and sponsorship tiers.
  - Full GDPR & ICO-compliant data protection terms, data retention transparency, and explicit consent handling.
- **Interactive Ticket Booking & FAQ Accordion**: Clear tiers for general admission, VIP front-row passes, and couple packages.
- **Venue & Travel Direction Guide**: Direct transit info, interactive maps, and landmark navigation.

## Tech Stack

- **Semantic HTML5** & **Vanilla CSS3** (Modular, responsive design system, custom CSS properties)
- **Vanilla JavaScript (ES6+)** (Interactive filtering, dynamic cost calculation, form validation, and toast feedback)

## Getting Started

To view or develop locally:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js npx
npx serve .
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.
